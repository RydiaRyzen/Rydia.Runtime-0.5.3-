01

はじめに

学習内容

Rydia Engine の基本構成や、GameStudio の役割を学びます。

ランチャー要件

Rydia Engine Launcherを起動するには、 .NET 9.0 + OpenGL ES 2.0 または 3.0 が必要です。 グラフィクスバックエンドは今後追加する予定です

エディター要件

エディターは現在 Windows 専用ですが、 macOS、Linux での開発も視野に入れています。

ランチャーと同じく、 .NET 9.0 + OpenGL ES 2.0 または 3.0 が必要です。

エンジンとエディターの役割

Rydia Engine は、エディター・ランチャーの どちらでも必要となるクラスを用意しています。

Rydia GameStudio は、Rydia Engine Launcher で使用する ゲームオブジェクトを管理・作成するためのツールです。

プロジェクトの構成

  • Assets フォルダー

    Rydia Engine Launcher で使用する すべてのゲームオブジェクトが格納されているフォルダーです。

  • Source フォルダー

    Media フォルダーと Code フォルダーが格納されています。

  • Media フォルダー

    Rydia GameStudio でインポートした音楽ファイル、 画像、フォントなどが格納されている場所です。

  • Code フォルダー

    ソリューションファイルが配置されています。 独自の Component を作成するには、 C# コードを書く必要があります。
