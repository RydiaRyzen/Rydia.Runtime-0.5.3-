# Rydia Engine, Rydia GameStudio, Rydia Runtime

Rydia.RuntimeはDesktopプラットフォーム(Windows, Macos, Linux), Mobileプラットフォーム(Android, iOS)で、
クロスプラットフォームを実現するために必要なIMessageServiceやIDeskPlatform, IMobilePlatformなど
必要なインターフェースやクラスを提供します

Rydia Runtime WindowsはWindowsでOpenGL ES2.0, 3.0、OpenALを実行するために必要なランタイムが含まれます
Rydia Runtime DroidはAndroidでOpenGL ES2.0, 3.0, OpenALを実行するために必要なランタイムが含まれます

Rydia.EngineはRydia.Runtime上で動作するゲームエンジンです
Rydia.GameStudioはRydia.Engineで使用するゲームオブジェクトやコンポーネントを動的に作成するツールです
